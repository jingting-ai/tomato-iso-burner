番茄镜像刻录工具 v1.2.49 —— 本版改了什么
================================================

一、修掉「打开就报错、U 盘读不到」
--------------------------------
上一版我在磁盘枚举脚本里把一行注释错写成了 JS 的 `//`
（PowerShell 的注释是 `#`），结果整段枚举脚本解析失败 ——
界面上就是「未能获取磁盘列表」，U 盘自然一个都读不到。
已修正；两段脚本（磁盘枚举 / USB 接口版本）都重新做过语法与运行验证，
你的 U 盘（磁盘 #2）实测能正常列出、且判定为 USB 3.0 接口。

二、U 盘修复的入口改成顶栏小按钮
--------------------------------
按你说的：做成小按钮，放在「关于」左边，带一个「?」悬停提示，
不再摆在主界面上（原来那条横幅确实太突兀，已删掉）。

  [🔧 修复 ?] [♡ 关于] [主题三连]

  · 点一下 → 切到「U 盘修复」模式，按钮变成强调色；
  · 再点一下 → 切回「整盘镜像刻录」；
  · 鼠标停在「?」上看说明（点「?」本身不会切换模式）。

三、U 盘修复失败的真因（上一轮那个）已经修了
--------------------------------
DiskPart 脚本模式下只要有一条命令出错就整体退出，而第三条
「online disk」对本来就联机的 U 盘必然报错，导致后面的
clean / 建分区 / 格式化 根本没执行。现在每条命令都带 noerr，
并且 diskpart 拿不到盘符时会自动改用存储模块再试一次。

================================================

二、U 盘现在会显示接口版本
--------------------------------
设备列表里每块 U 盘会多一个小标签，写明它插在哪种接口上：

    USB 3.0   ← 绿色（5 Gbps，刻录快）
    USB 2.0   ← 黄色（会明显慢，6 GB 的镜像可能要刻十几分钟）

判定方法：从磁盘的 PnP 节点沿「父设备」链往上找，看它挂在哪一代根集线器上
（ROOT_HUB30 = USB 3.0，ROOT_HUB20 = USB 2.0）。说的是**这个口**的版本，
不是设备自身的速率 —— 你要的正是「接口版本」。

两点说明：
· 判不出来就不显示，绝不猜一个糊弄人；
· 这个查询要沿设备链一层层问，每层约 0.7~0.9 秒。为了不拖慢「刷新」，
  它是**后台补查**的：列表先出来，那一两个小标签晚一两秒补上。
  同一块盘查过一次就记住了，之后刷新不再重查。
