Doro 镜像刻录工具 v1.2.27 —— 使用说明
=================================================


【这一版只改了两件事，都跟图标有关】

  1) 外面看到的图标，全部换成新的「蓝底 Doro镜像刻录」样式；
  2) 软件界面里的那个小头像，改回白底（这一版之前我误改成了灰底）。


【一、外面看到的图标，换成了新样式】

  「外面」指的是所有不在软件界面里的图标，这一版全部换掉了：

    · 主程序文件本身的图标（在文件资源管理器里看到的那个）
    · 桌面快捷方式、开始菜单、任务栏固定的图标
    · 窗口左上角的图标
    · 安装包（安装向导、卸载程序）的图标

  新样式就是蓝底圆角方块 + Doro 头像 + 一个「光盘 → U 盘」的小箭头
  + 白色「Doro镜像刻录」字样。

  技术上说明一句，方便你核对：这些图标都嵌在主程序 exe 文件里面，
  所以换图标必须连 exe 一起换 —— 只替换 resources 文件夹是不够的。
  本版发布时已经确认：绿色版、便携版、安装包三个 exe 里都已经嵌入了新图标
  （16 / 24 / 32 / 48 / 64 / 128 / 256 七种尺寸齐全）。


【二、软件界面里的小头像，改回白底】

  顶栏左上角 38px 和「关于」面板里 46px 的头像，这一版恢复成白底。

  v1.2.23 我把它改成了灰底（当时想让它和系统图标看起来「统一」），
  这是我的理解错了 —— 你要的是「界面里保持白底，把外面的图标改成新风格」。
  现在两条线彻底分开了，以后不会再互相牵连。


【关于界面里的小头像 vs 外面的图标 —— 两者不是同一张图，这是故意的】

  界面里头像：白底，就是原来那张 Doro 头像（头顶柿子 + 粉发 + 紫蝴蝶结）；
  外面图标：  蓝底圆角方块，带「Doro镜像刻录」字样，适合在任务栏/桌面上辨认。

  所以看到界面里还是白底，不是没改 —— 外面才改了。


【怎么确认你用的是新版】

  · 程序底栏显示 v1.2.27 Beta；
  · 文件资源管理器里看主程序，图标是蓝底「Doro镜像刻录」；
  · 打开「关于」面板，左上角头像是白底的。


【一个必须知道的坑：图标缓存】

  Windows 会缓存图标。如果你的桌面快捷方式 / 任务栏固定项还是显示旧图标，
  不是没换成功，是系统没刷新：

    · 最省事：把快捷方式删掉，重新从程序目录右键「发送到 → 桌面快捷方式」；
    · 任务栏固定项：先「从任务栏取消固定」，再重新固定；
    · 还不行就重启一次资源管理器，或者注销重登。


【怎么用新版本】

  绿色版（推荐）：
    双击本目录里的 Doro镜像刻录工具.exe。
    桌面上那个「Doro镜像刻录工具 v1.2.4」快捷方式指向的目录
    （E:\DoroBurner-1.2.4）也已经同步成 v1.2.27，图标和界面都是新的。

  安装版：
    双击 安装包\Doro镜像刻录工具-1.2.27-win-x64.exe（需要管理员确认）。
    装完开始菜单和公共桌面那两个快捷方式也会跟着变成新版。

  注意：C:\Program Files\doro-iso-burner 那套安装版，我这边没有管理员权限写不进去，
  所以它还停在旧版本。要更新它，跑上面这个安装包就行。
