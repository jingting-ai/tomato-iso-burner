Doro 镜像刻录工具 v1.2.34 —— 使用说明
=================================================


【这一版：去掉双平台，界面一律按 Windows 单平台写】

  你说现在没有 macOS 环境了、macOS 先不开发，所以凡是提到「跨平台 / Windows / macOS」
  的地方都改掉了。改的是这几处（都在界面上看得见）：

    顶栏副标题   跨平台 · Windows / macOS        →  Windows 版 · 本地离线运行
    关于副标题   跨平台镜像刻录工具 · Windows / macOS →  Windows 镜像刻录工具 · 本地离线运行
    功能卡片     跨平台 · 双主题                  →  双主题（地球图标换成半明半暗的圆）
    权限提示     加上「，macOS 请以 root 启动」     →  去掉了，只留 Windows 的说法
    格式化说明   exFAT「跨平台 · 支持大文件」       →  「各系统通用 · 支持大文件」
                 （这条说的是文件系统本身在别的系统上也能读，不是说本程序支持 macOS）

  另外把工程里的双平台痕迹也收拾了：
    · README 的整体说明、平台对照表（原来是 Windows / macOS 两列）、打包章节里的
      macOS 构建步骤、macOS 首次运行提示 —— 全部改成 Windows 单平台；
    · `package.json` 描述、以及 `dist:mac` / `dist:mac:arm` 两条打包命令删掉了；
    · 打包配置里的 macOS 段（dmg / zip、mac 图标）整段摘掉了，但**注释保留**，
      将来要在 mac 上打包，把那段加回来就行。


【有两样东西我特意留着，说明一下】

  一、源码里的 macOS 适配层（`src/main/platform/darwin.ts`、`plist.ts` 等）没有删。
      你说的是"先不开发"，不是"永远不要"，删了将来要重写。它们现在是死代码，
      不影响 Windows 版任何行为，也不会有任何 macOS 字样出现在界面上。

  二、**镜像识别**里仍然认得 macOS 安装镜像 —— 打开一个 macOS 的 ISO/DMG 时，
      会照常标出「macOS」家族。那说的是**你手里这个镜像是什么系统的**，
      不是本程序支持 macOS。你要是觉得这个也碍眼，说一声，一起去掉。
