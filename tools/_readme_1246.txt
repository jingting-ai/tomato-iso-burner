番茄镜像刻录工具 v1.2.46 —— 本版改了什么
================================================

只修一件事：**顶栏那条分隔线走到右上角窗口按钮那儿就断了**（你的原话：
「就是做成不是一个整体的了，分割开了，到 x 窗口那里，割裂开了」）。

原因
--------------------------------
右上角那三个窗口按钮（最小化 / 最大化 / 关闭）不是网页画的，是系统叠在网页
之上的一层不透明色块，它会**盖住自己底下那一块网页内容**。

而顶栏是「高 62px + 下边框 1px」，全局又是 border-box —— 那条分隔线正好占在
第 61~62px，**落在叠层里面**，于是右边约 136px 的一段线被叠层吃掉：

    改之前：  左 100%  ▏中 100%  ▏右 54%   ← 线到按钮那儿断了
    改之后：  左 100%  ▏中 100%  ▏右 100%  ← 横贯整窗

（上面这三个数是拿截图逐像素量出来的，不是估计的。）

怎么修的
--------------------------------
把窗口按钮叠层的高度设成 **61px**（顶栏 62px 减 1px），让那条 1px 分隔线
露在叠层外面。顶栏的内容区本来就是 61px（62 减掉边框），所以按钮的垂直居中
一点没动，不会错位。

主窗口和「关于」窗口都是同一套做法，一起改了。
