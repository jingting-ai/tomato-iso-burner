番茄镜像刻录工具 v1.2.48 —— 本版改了什么
================================================

一、「U 盘修复」不再藏着了
--------------------------------
你说「好像没看到修复U盘的功能选项」——它确实在，但只作为「写入方式」下拉框里的
**第三项**，太不显眼，等于没有。

现在在非修复模式下，「写入方式」下面会直接摆一条：

    U 盘有问题？ 打不开 / 容量显示不对 / 提示「需要格式化」/ 没有盘符
                                             [ 用「U 盘修复」救回来 ]

点一下就切到修复模式。切过去之后这条提示自动收起，换成修复的四步说明。

顺带说明一下：这个功能从 v1.2.45 就有了，你当时跑的 1.2.46 里也确实带了
（程序日志里能看到）。之前纯粹是入口藏得太深，这次改的就是这个。


二、U 盘现在会显示接口版本：USB 2.0 / USB 3.0
--------------------------------
设备列表里每块 U 盘会多一个小标签，写明它插在哪种接口上：

    USB 3.0   ← 绿色（5 Gbps，刻录快）
    USB 2.0   ← 黄色（会明显慢，6 GB 的镜像可能要刻十几分钟）

判定方法：从磁盘的 PnP 节点沿「父设备」链往上找，看它挂在哪一代根集线器上
（ROOT_HUB30 = USB 3.0，ROOT_HUB20 = USB 2.0）。说的是**这个口**的版本，
不是设备自身的速率 —— 你要的正是「接口版本」。

两点说明：
· 判不出来就不显示，绝不猜一个糊弄人；
· 这个查询要沿设备链一层层问，每层约 0.7~0.9 秒。为了不拖慢「刷新」，
  它是**后台补查**的：列表先出来，那一两个小标签晚一两秒补上。
  同一块盘查过一次就记住了，之后刷新不再重查。
