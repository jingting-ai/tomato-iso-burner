番茄镜像刻录工具 v1.2.45 —— 本版改了什么
================================================

**U 盘修复做进程序里了**（你的原话：「把 u 盘修复功能做到程序里面，修复完成能
正常使用的 U 盘 ntfs 格式的」）。以前它只是发布包里一个独立的命令行工具，
现在主界面里就能用。

怎么用
--------------------------------
1. 插上读不出 / 容量异常 / 提示需要格式化的 U 盘；
2. 在「写入方式」那个下拉框里选 **「U 盘修复（把读不出 / 容量异常的盘救回来）」**；
3. 在下面选中那块盘 → 勾选确认 → 点「开始修复」；
4. 完成后它会变成 **NTFS 格式**（默认就是 NTFS，也可以改成 exFAT / FAT32），
   并自动分配盘符 —— 在「此电脑」里就是一块能直接用的普通 U 盘。

修复做的四件事（界面上会列出来，日志里也会逐条打印）：
  ① 打开设备并清除只读属性
  ② 刷新磁盘几何（修「0 字节 / 未初始化 / 没有媒体」）
  ③ 盘头写零，抹掉镜像与损坏分区表的残留签名
  ④ diskpart 重建分区表并格式化、分配盘符


「深度扫描」：连系统认不出的盘也能找到
--------------------------------
刻录失败后的 U 盘常常连「此电脑 / 磁盘管理」里都列不出来 —— 常规刷新走的是
Windows 的磁盘枚举，看不到它就选不到它，也就修不了。

所以设备列表右上角多了一个 **「深度扫描」** 按钮：它直接扫 \\.\PhysicalDrive0..15，
把这种「隐身盘」补进列表（会标注「系统认不出这块盘」）。找到之后就能像正常 U 盘
一样选中并修复。


安全
--------------------------------
· 修复只针对 U 盘 / 移动硬盘：**内置硬盘、系统盘、含 C: 的盘一律拒绝**；
· 界面上仍然要先勾选「我已确认目标磁盘选择无误」才能开始；
· 全程走运行日志，每一步都看得见（出问题把日志发我就行）；
· 修复会清空这块盘上的全部数据，不可撤销。

（下面两版一并附上）
================================================

v1.2.44
  · 「关于」窗口改成与主程序同款的合并标题栏（不再多一条系统灰条），
    页面里那颗「×」去掉了，右上角系统按钮就是关闭。

v1.2.43
  · 修掉「写入首块（分区表）失败（已成功写入 14.15 GB）」那个真实故障：
    清分区表时残留的幽灵分区占着 0 扇区，导致最后写首块被错误码 5 拦住。
    现在清分区表「不达目的不罢休」，首块写入失败也走完整自救。
  · 失败提示里写死的过期路径改成动态探测。

v1.2.42
  · 「关于 / 捐赠」改成独立窗口；「关于」「捐赠」拆成两个入口，点「捐赠」直达收款码；
    右上角控件统一语言。
  · 刻录过程日志：每跨 10% 一条 + 60 秒心跳。

怎么更新
================================================
· 安装版：先**完全退出程序**，再双击 安装包\番茄镜像刻录工具-1.2.45-win-x64.exe
